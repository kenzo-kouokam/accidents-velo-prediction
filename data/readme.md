# Dataset

Ce projet utilise un jeu de données public sur les accidents de vélo en France.

## Source
- Dataset : [Accidents de vélo | data.gouv.fr](https://www.data.gouv.fr/datasets/accidents-de-velo)
- Source institutionnelle : [ONISR Open Data](https://www.onisr.securite-routiere.gouv.fr/outils-statistiques/open-data)

## Description
Ce jeu de données recense les accidents corporels impliquant au moins une personne à vélo en France.  
Il est construit à partir du fichier national des accidents corporels de la circulation (BAAC), administré par l’ONISR.

## Remarque
Le dataset n’est pas stocké dans ce dépôt GitHub afin d’éviter d’alourdir le repository.  
Pour reproduire l’analyse, il suffit de télécharger les données depuis la source officielle puis de les placer localement dans le dossier `data/` si nécessaire.
